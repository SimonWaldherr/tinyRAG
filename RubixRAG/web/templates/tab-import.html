Import

Dokumente, Postfächer und Server-Ordner in die Wissensbasis aufnehmen.

Dateien importieren

TXT, MD, CSV/TSV, JSON/JSONL, HTML, EML/MBOX, MHTML, VCF, ICS und SRT/VTT nativ. DOCX/DOCM/PPTX/PPTM/XLSX/XLSM/PDF/RTF/ODT/… über markitdown; Audio/Video und .7z benötigen zusätzlich die konfigurierten externen Werkzeuge.

Dateien hierher ziehen oder klicken Keine Dateien ausgewählt

PST-/OST-Postfach importieren

Outlook-.pst- oder .ost-Export. Nach dem Hochladen zeigt R3 die enthaltenen Ordner mit Nachrichtenzahl zur Auswahl, bevor tatsächlich importiert wird. Jede E-Mail wird als eigene, zitierbare Quelle gespeichert; ein erneuter Import derselben Datei ersetzt nur geänderte Nachrichten.

Für sehr große Postfächer (mehrere GB) ist ein Browser-Upload oft unzuverlässig oder langsam. Alternativ kann die Datei direkt auf dem Server abgelegt werden (z.B. per Netzlaufwerk oder scp) — dann hier den vollständigen Pfad auf dem Server angeben, ganz ohne Upload:

    SharePoint importieren

    Listet Dateien in einem SharePoint-Ordner (eine Ebene) und importiert die ausgewählten. Erfordert eine konfigurierte Azure-AD-App-Registrierung unter „Einstellungen → SharePoint". Jede „Site-URL" dort ist genau eine SharePoint-Site — Unterordner wie „Freigegebene Dokumente" gehören NICHT ins Site-URL-Feld, sondern in den Ordnerpfad unten; oft ist z.B. „Support/Logistik" tatsächlich eine eigene Unter-Site und braucht eine eigene, zusätzliche Verbindung.

      Importiert/löscht nur, was sich seit dem letzten Delta-Sync geändert hat — unabhängig vom Ordnerpfad oben, für das ganze Drive.

      Site Pages (.aspx-Seiten)

      Die eingebauten Wiki-/News-/Landingpages einer Site (z.B. „Neue-Mailstruktur-in-der-Logistik.aspx") liegen in einer separaten Bibliothek, die der Ordner-Import oben nicht sieht — hier werden sie eigens aufgelistet. Nur Text-Textbausteine der Seite werden gelesen; Bilder/Einbettungen/Listen-Web-Parts tragen nichts bei.

        Freigabe-Link importieren

        Ein einzelner, per „Link kopieren" geteilter Link (.../:b:/..., .../:x:/... usw.) — auch aus einer Site, die oben nicht als eigene Verbindung konfiguriert ist, solange die Azure-AD-App für DIESE Site per Sites.Selected freigegeben wurde. Ein Link pro Zeile.

        OneDrive for Business

        Synchronisiert den in den Einstellungen angelegten Drive über Microsoft Graph Delta. Neue, geänderte, verschobene und gelöschte Dateien werden verarbeitet; der Lauf setzt beim nächsten Aufruf am gespeicherten Delta-Cursor fort.

        GitHub

        Synchronisiert README, Issues und Pull Requests des konfigurierten Repositories. Große Erstimporte werden über mehrere Läufe fortgesetzt; unveränderte Dokumente werden übersprungen.

        SAP S/4HANA (OData)

        Synchronisiert genau die konfigurierte OData-Entity. Der Import liest nur die in den Einstellungen freigegebenen Felder und nutzt einen Delta-Link, sofern der SAP-Service einen anbietet.

        Outlook / Exchange Online (Microsoft Graph)

        Listet die neuesten Nachrichten in einem freigegebenen Postfach und importiert die ausgewählten. Erfordert eine Azure-AD-App-Registrierung unter „Einstellungen → Outlook/Exchange". Für On-Prem-Exchange oder IMAP-Postfächer siehe die IMAP-Karte weiter unten.

          Microsoft Teams (Kanal-Nachrichten)

          Listet die neuesten Beiträge im konfigurierten Kanal und importiert die ausgewählten (nur Hauptbeiträge, keine Thread-Antworten). Erfordert eine Azure-AD-App-Registrierung unter „Einstellungen → Microsoft Teams".

            IMAP (On-Prem Exchange / generische Postfächer)

            Holt alle Nachrichten, die seit dem letzten Lauf neu im Postfach eingegangen sind (kein Vorschau-/Auswahlschritt nötig — IMAP-UIDs sind bereits fortlaufend und werden nicht doppelt importiert). Erfordert Zugangsdaten unter „Einstellungen → IMAP".

            Confluence

            Listet die zuletzt geänderten Seiten im konfigurierten Space und importiert die ausgewählten. Erfordert einen API-Token unter „Einstellungen → Confluence".

              Jira

              Listet die zuletzt geänderten Issues im konfigurierten Projekt und importiert die ausgewählten. Erfordert einen API-Token unter „Einstellungen → Jira" (derselbe Atlassian-Token wie für Confluence funktioniert, falls der Account beides lesen darf).

                Freshservice

                Listet die zuletzt geänderten Tickets und importiert die ausgewählten. Erfordert einen API-Key unter „Einstellungen → Freshservice". Kann dort zusätzlich auf automatischen periodischen Sync gestellt werden, statt nur hier per Hand zu importieren.

                  Webseite (URL-Import)

                  Holt eine oder mehrere Webseiten per HTTP(S) und importiert den extrahierten Text. Optional rekursiv: folgt Links auf der Seite, um eine ganze Website zu erfassen. Kein Setup nötig — aber der Server ruft exakt die eingegebenen URLs (bzw. beim Crawlen: von dort aus erreichbare Seiten) ab, also nur URLs aus vertrauenswürdigen Quellen einfügen (eine URL pro Zeile).

                  RSS / Atom-Feed importieren

                  Liest die Einträge eines öffentlichen RSS- oder Atom-Feeds ein. Bereits bekannte Einträge werden über ihre Feed-ID bzw. URL übersprungen.

                  Server-Ordner importieren

                  Rekursiver Import eines Ordnerpfads auf dem Server — auch für SMB-Freigaben, wenn diese zuvor vom Server als lokaler Pfad eingehängt wurden.

                  🐕 R3-Quellcode importieren

                  Lädt R3s eigenen Quellcode (Go/JS/CSS/HTML/Markdown) in die eigene Wissensbasis, damit R3 auch Fragen zu seiner eigenen Implementierung beantworten kann — mit Zitat auf die jeweilige Datei. Läuft ausschließlich im Arbeitsverzeichnis des Server-Prozesses; Einstellungsdateien mit Zugangsdaten (z. B. settings.json) und andere sensible Pfade werden dabei grundsätzlich ausgeschlossen. Rein optional — dieser Import startet nie automatisch.
