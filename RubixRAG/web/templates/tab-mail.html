Mail-Entwurf

Antwort auf eine eingehende E-Mail oder eine neue E-Mail aus Stichpunkten — gestützt auf die Wissensbasis. Immer nur ein Vorschlag zur Prüfung durch einen Menschen; R3 versendet nichts automatisch.

Mein Postfach

Zeigt E-Mails direkt aus einem Postfach (Microsoft Exchange), ohne Copy-and-Paste — Auswahl füllt die Eingabe unten automatisch. Nur sichtbar, wenn ein Admin dies für dein Konto freigeschaltet hat.
