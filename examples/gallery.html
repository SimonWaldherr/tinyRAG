tinyRAG — Theme & Scenario Gallery

A static, self-contained reference (shipped inside the binary via go:embed) for every built-in theme and deployment scenario template. Apply any of them from Settings → Appearance, via POST /api/ui/templates/apply, or headlessly with tinyRAG -apply-template <id>.

Themes

14 ready-made CSS-variable themes, layered on a light or dark base. See docs/ui-customization.md for the custom-theme format.

Scenario templates

Each bundles a theme, a density, and a full UI configuration (panels, chat modes, pickers, suggestions) — a one-click starting point for a specific product shape.
